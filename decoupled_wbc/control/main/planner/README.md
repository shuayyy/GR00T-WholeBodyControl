# Run

Three terminals, from the repo root:

```bash
# 1. simulation + RL policy; press ] (start), wait 2 s, press 9 (release the band)
python decoupled_wbc/control/main/planner/run_g1_control_loop.py

# 2. planner server
python decoupled_wbc/control/main/planner/run_planner_server.py \
    --use-reference --reference-trajectory-path dataset/ICRA/pour/traj.npz \
    --planning-timeout 30 --ompl-planner PhaseRRTstar

# 3. request: start = demo frame 0, goal = demo last frame
python decoupled_wbc/control/main/planner/example_planner_request.py --trajectory-path dataset/ICRA/pour/traj.npz
```

Demos: `dataset/ICRA/<task>/traj.npz` (`wave`: `traj_half.npz`).

## Options

| flag | meaning |
|---|---|
| `--ompl-planner` | `RRTstar`, `RRTConnect`, `PhaseRRTstar` |
| `--planning-xml` | scene, default `simulation/envs/g1_free.xml` (others in `simulation/envs/`) |
| `--no-record` | skip saving `recordings/<time>_<planner>.npz` (robot state + sent goals + metrics) next to the reference |
| `--max-joint-step` × `--planner-frequency` | execution speed (0.025 rad × 20 Hz = 0.5 rad/s) |
| `--smooth-path` / `--no-smooth-path` | **on by default**: the plan is replaced by a cubic smoothing spline (`trajectory_ops.smooth_spline`, endpoints pinned, `s = 0.005·N`) before resampling; any sample that collides is pulled back toward the raw path. Worst corner on dual arm sweep: 96° raw → ~10° |
| `--validation-xml` | scene the smoothed path is checked against; default = the planning scene. Set it when `--planning-xml` carries inflated obstacles (`g1_obstacle_<x>.xml` → `g1_obstacle_<x>_true.xml`) |
| `--phase-sigma-scale` | PhaseRRT* sampling width, multiple of the default `0.0018·L`; 1.0 = free space, 10 for obstacle scenes |
| `--validity-resolution` | OMPL edge-check step as a fraction of space extent; 0.01 default, 0.002 used for obstacle scenes |

### Obstacle scenes

```bash
python decoupled_wbc/control/main/planner/run_planner_server.py \
    --use-reference --reference-trajectory-path dataset/ICRA/dualarm_sweep/traj.npz \
    --planning-xml simulation/envs/g1_obstacle_dualarm_sweep_table.xml \
    --validation-xml simulation/envs/g1_obstacle_dualarm_sweep_table_true.xml \
    --planning-timeout 30 --ompl-planner PhaseRRTstar --phase-sigma-scale 10 --validity-resolution 0.002
```

Scenes are generated by `obstacle_lab.py` (repo root): the `_true` file has the obstacle at its real size, the other has its collision geom grown by `CLEARANCE` (10 mm) so the tree keeps a margin.
